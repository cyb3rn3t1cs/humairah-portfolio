# Humairah Adamu Sidi — Portfolio

A responsive, static portfolio site designed for Vercel.

## Features
- Responsive navigation and section-based portfolio layout
- Scroll-triggered reveal animations
- Animated count-up metrics
- Interactive, fictional SOC investigation exercise (Humairah Cyber Lab)
- Project category filters
- Downloadable CV
- Reduced-motion accessibility support

## Deploy to Vercel
This is a static website; no build command or framework preset is required.

1. Extract this folder.
2. Create a GitHub repository and upload the contents of this folder (the `index.html`, `styles.css`, `script.js`, `vercel.json`, `assets/` folder and CV should be at the repository root).
3. Sign in to Vercel and choose **Add New → Project**.
4. Import that GitHub repository.
5. Select **Other** as the framework preset. Leave Build Command and Output Directory blank (or use `.` as the output directory).
6. Click **Deploy**. Vercel will provide the public `*.vercel.app` URL.
7. To update the site later, commit and push changes to the connected GitHub repository; Vercel redeploys automatically.
